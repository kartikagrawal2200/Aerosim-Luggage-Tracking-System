# AeroSim - Baggage Tracking & Airport Management System
**CSE 326 Project (CA-2)**

AeroSim is a modern, responsive web application designed for smart baggage tracking and passenger flight information management. It allows passengers to follow each stage of their luggage's journey from check-in through departure, transit, and baggage carousel retrieval.

## 🌐 Live Website (GitHub Pages)
👉 **[View Live Site](https://kartikagrawal2200.github.io/Aerosim-Luggage-Tracking-System/)**

---

## 🚀 Features
- **Smart Luggage Tracking**: Look up baggage status using tag IDs (e.g., AS1092).
- **6-Stage Baggage Journey**: Check-in, security screening, sorting, ramp loading, transit transfer, and carousel arrival.
- **Flight & User Profile**: Manage flight bookings and view user travel details.
- **Responsive & Modern UI**: Built with responsive layouts, modern typography, and glassmorphism styling.
- **Complete Portal**: Includes Home, About, Contact, Tracking, Profile, Register, Login, Privacy Policy, and Terms pages.
